# benji-taste

An unofficial, evidence-derived Agent Skill for designing, implementing, and reviewing polished UI/UX using recurring principles in Benji Taylor's public work.

## Contents

- `SKILL.md` — the agent-loadable skill
- `references/EVIDENCE.md` — research provenance and derivation map
- `references/EVALS.md` — test prompts and assertions for evaluating the skill

## Install

Copy the `benji-taste` directory into the skills directory used by an Agent Skills-compatible client. The directory name must continue to match the `name` field in `SKILL.md`.

Examples include a project-local `.claude/skills/benji-taste/` directory or the corresponding skills location in another compatible client.
